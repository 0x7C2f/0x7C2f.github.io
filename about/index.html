About 0x7C2f

Programmer exploring code, commerce, and consciousness.

What This Site Is

0x7C2f.github.io is a static, hand-written workspace hosted on GitHub Pages with no framework, no analytics, and no build pipeline. The homepage doubles as a daily keyboard-driven startpage, and the rest of the site holds technical guides, interactive browser experiments, and a curated reading archive.

What Lives Here

Startpage

Keyboard-first web search across DuckDuckGo, Google, Brave, SearXNG, and YouTube, paired with categorized quick-launch bookmarks.

Blog & Guides

Notes on MCP tooling, static hosting constraints, and essays on economics and opportunity cost.

PDF Library

A direct-download shelf of reference books and essays on programming, markets, security, and philosophy.

Doppler Simulator

Interactive acoustic Doppler pass simulator that pinpoints observer coordinates from frequency inflection timing and slope steepness.

Fluid Visualizer

GPU WebGL Stable-Fluids simulation paired with a live FFT audio-reactive layer supporting microphone input, local audio files, and a built-in generative beat.

MCP Servers JSON

Static JSON endpoint listing curated Model Context Protocol server repositories for programmatic discovery and tooling.
